Privacy Policy

Effective 2 October 2026

This application has one user, shares nothing, and has no server of its own. It shows the author’s own calendar on a screen in the author’s own home. Everything below is detail supporting that sentence. If any part of this policy ever stops being true, this page will be updated before the change takes effect.

Who operates this application

An individual, for personal use in a private residence. There is no company, no staff and no other user. Contact: DanielGMusto@gmail.com.

What access is granted, and what is actually used

The author authorises this application with Google’s Calendar scope (https://www.googleapis.com/auth/calendar), which is what Home Assistant’s Google Calendar integration requests. In use:

Calendar listThe names of the calendars the author’s account can see, including any a family member has chosen to share with the author
EventsTitle, start and end time, location and description of upcoming events, read to display them on a screen at home and to drive the home’s own reminders
New eventsCreated only when the author explicitly asks Home Assistant to add one. Existing events are never edited or deleted

No other Google account data is requested or used. Not contacts, not mail, not Drive, not location history, not photos, and no profile information beyond what is strictly required to complete the OAuth sign-in.

Where that data goes

Directly from Google’s Calendar API to a self-hosted Home Assistant instance running on hardware the author owns, on a private home network. There is no intermediate server, no cloud service, and no hosted component operated by this application. Upcoming events are held in that instance only for as long as needed to show them.

What is never done with it

  • Not shared with any third party, for any purpose.
  • Not sold, rented, traded or licensed. Ever, under any circumstances.
  • Not used for advertising, profiling, or ad targeting.
  • Not used to train machine-learning or AI models.
  • No analytics, telemetry or tracking of any kind. This website sets no cookies, loads no external scripts, fonts or images, and logs no visitors.
  • Not transferred to any other jurisdiction, processor or sub-processor, because there are none.

Retention and deletion

Calendar data remains in the author’s Google account, where the author manages it. The home instance keeps only what it is currently displaying, plus any history the author’s own Home Assistant retention settings keep, all of which the author can purge at any time. No copy exists anywhere else.

Revoking access

Access can be withdrawn at any moment from Google Account permissions. Revocation is immediate: the application loses all ability to read or write the calendar.

Security

OAuth credentials and tokens are stored on the author’s own equipment on a private network, are not transmitted to any third party, and are not embedded in any distributed software — this application is not distributed at all.

Children

This application is not directed at children and has no users other than its operator.

Changes to this policy

Any change will be published on this page with a revised effective date. As there are no other users, no notification mechanism exists or is required.
