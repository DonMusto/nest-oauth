Privacy Policy

Effective 21 September 2026

This application has one user, collects nothing, shares nothing, and has no server. Everything below is detail supporting that sentence. If any part of this policy ever stops being true, this page will be updated before the change takes effect.

Who operates this application

An individual, for personal use in a private residence. There is no company, no staff and no other user. Contact: DanielGMusto@gmail.com.

What data is accessed

Only data about the operator’s own Nest device, retrieved from Google’s Smart Device Management API under authorisation granted by the operator’s own Google account:

Thermostat stateCurrent temperature, humidity, HVAC mode, operating status and target setpoint
Device metadataDevice name, type, and the structure or room it is assigned to
Change eventsNotifications delivered via Google Cloud Pub/Sub when the above values change

No other Google account data is requested or accessed. Not contacts, not calendar, not mail, not location history, not files, not profile information beyond what is strictly required to complete the OAuth sign-in.

⚠ This application does not access cameras, doorbells, microphones or any video or audio stream, and does not request the scopes that would permit it.

Where that data goes

Directly from Google’s API to a self-hosted Home Assistant instance running on hardware the operator owns, on a private home network. There is no intermediate server, no cloud service, and no hosted component operated by this application.

Thermostat readings are stored in that instance’s local database so that history and automations work, exactly as with every other device in the home. That database is on the operator’s own hardware and is not replicated to any external party.

What is never done with it

  • Not shared with any third party, for any purpose.
  • Not sold, rented, traded or licensed. Ever, under any circumstances.
  • Not used for advertising, profiling, or ad targeting.
  • Not used to train machine-learning or AI models.
  • No analytics, telemetry or tracking of any kind. This website sets no cookies, loads no external scripts, fonts or images, and logs no visitors.
  • Not transferred to any other jurisdiction, processor or sub-processor, because there are none.

Retention and deletion

Thermostat history is retained locally under Home Assistant’s own retention settings and can be purged by the operator at any time. Because no copy exists anywhere else, deleting it locally deletes it completely.

Revoking access

Access can be withdrawn at any moment from Google Account permissions. Revocation is immediate: the application loses all ability to reach any device, and no further data can be retrieved.

Security

OAuth credentials and tokens are stored on the operator’s own equipment on a private network, are not transmitted to any third party, and are not embedded in any distributed software — this application is not distributed at all.

Children

This application is not directed at children and has no users other than its operator.

Changes to this policy

Any change will be published on this page with a revised effective date. As there are no other users, no notification mechanism exists or is required.
