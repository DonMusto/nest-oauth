Home Assistant Nest Link

A private, single-user integration that lets one self-hosted Home Assistant installation read and control one household’s own Nest thermostat.

This application has exactly one user: its author. It is not distributed, not published to any app store, not offered as a service, and accepts no sign-ups. It exists solely so that a thermostat in a private residence can be managed from the home-automation software that already runs that residence.

What it does

Nest thermostats provide no local API. Unlike the lighting, media and printing devices in this household — all of which are controlled locally over the home network with no external account — the thermostat can only be reached through Google’s Smart Device Management (SDM) API.

This application is the OAuth client that makes that connection. Once authorised, it allows the owner’s self-hosted Home Assistant instance to:

  • read the thermostat’s current temperature, humidity, mode and setpoint;
  • change the setpoint and operating mode;
  • receive push updates when the thermostat’s state changes, via Cloud Pub/Sub.

Where the data goes

To a server on a private home network, owned and operated by the author, and nowhere else. There is no hosted backend, no analytics, no third-party processor and no other recipient of any kind. The full detail is in the privacy policy.

Scope of access

Access is limited to devices in the author’s own Google account, granted by that account, and revocable at any time from Google Account permissions. Revoking access immediately and permanently ends this application’s ability to reach any device.
